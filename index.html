Dashboard Guide

Overview First

The statistics cards at the top display key metrics about your healthcare data. You can also set your color vision profile (👁️ button) to optimize chart colors for better accessibility. Begin here to understand the overall dataset composition and patterns.

Filter & Explore

Use the filter controls to narrow down your data by test results, age groups, or medical conditions. Each filter update instantly reflects across all visualizations.

Test Outcome: Normal, Abnormal, or Inconclusive
Age Groups: 0-18, 19-40, 41-65, 65+
Medical Conditions: Cancer, Obesity, Diabetes, and more
Hospital Location: Click map markers for location-specific data

Interactive Visualizations

Click on any chart element to drill down into details. Hover over data points to see additional information. All charts are linked—filtering in one updates all others.

Hospital Map

The spatial view displays hospital locations with color-coded markers representing dominant test result types. Click any marker to filter all data by that facility.

Reset Filters

Use the Reset button at any time to clear all active filters and view the complete dataset again.
